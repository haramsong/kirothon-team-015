# 제품 개요: 나만의 냉장고

## 서비스명

- 서비스명: **나만의 냉장고** (확정)
- 영문 표기와 저장소 이름: `my-own-fridge` (GitHub 저장소 이름에 한글을 쓸 수 없어서 영문으로 둔다)
- 화면, 발표 자료, 문서에는 "나만의 냉장고"를 쓴다.

## 한 줄 소개

영수증이나 온라인 주문내역을 찍으면 냉장고 재고가 채워지고, 소비기한이 임박한 재료로 만들 메뉴를 추천받아 요리하면 쓴 재료가 자동으로 빠지는 서비스

## 대상 사용자

혼자 사는 직장인과 대학생 (1인 가구)

- 2024년 1인 가구는 804만 5천 가구로 전체 가구의 36.1%이며, 그중 약 60%가 취업 상태 (국가데이터처, 「2025 통계로 보는 1인가구」)

## 문제 정의

혼자 사는 직장인과 학생은 장 본 식재료를 다 쓰지 못하고 버리게 된다. 양파 1.5kg망이나 대파 한 단처럼 판매 단위는 혼자 먹기에 크고, 퇴근이나 수업 후에는 남은 재료로 무엇을 만들지 고민할 여유가 없다. 냉장고 관리 앱이 있지만 온라인으로 장을 보면 종이 영수증이 없어 등록이 번거롭다. 먹은 재료를 일일이 지우지도 않아서 목록이 금방 실제 냉장고와 달라지고, 결국 앱을 쓰지 않게 된다.

## 핵심 차별점

### 출발점이 된 관찰

기존 냉장고 앱은 재료를 **넣는 일**을 영수증 스캔으로 쉽게 만들었다. 하지만 다 먹은 재료를 **빼는 일**은 여전히 사용자가 직접 해야 한다. 빼지 않은 재료가 쌓이면 목록이 실제 냉장고와 달라지고, 틀린 목록을 바탕으로 추천된 메뉴는 만들 수가 없다. 사용자는 앱을 믿지 못하게 되고 결국 쓰지 않는다.

이 서비스는 등록, 추천, 요리, 차감을 하나의 흐름으로 묶어서 **재고 목록이 실제 냉장고와 계속 맞도록** 하는 데 집중한다.

```
장보기 → 등록 (영수증·주문내역 인식) → 추천 (임박 재료 우선) → 요리 → 차감 ("요리했어요")
   ↑                                                                        │
   └──────────────────────── 실제 냉장고와 맞는 재고 목록 ←─────────────────┘
```

### 차별점 1 (대표 차별점): 요리하면 재고가 알아서 줄어든다

- **문제**: 먹은 재료를 직접 지워야 해서 아무도 지우지 않는다. 그래서 목록이 금방 틀어진다.
- **해결**: 추천 레시피에 사용 재료와 수량(개)이 함께 나온다. "요리했어요"를 한 번 누르면 확인 화면을 거쳐 재고에서 빠진다.
- **화면에서 보여줄 것**: 차감 확인 화면에서 "양파 8개 → 7개"처럼 바뀌는 수량을 나란히 보여준다.

### 차별점 2: 종이 영수증이 없어도 사진 한 장으로 등록한다

- **문제**: 온라인으로 장을 보면 종이 영수증이 남지 않아서, 영수증 스캔 기능을 쓸 수 없고 직접 입력해야 한다.
- **해결**: 마트 영수증 사진과 온라인 주문내역 스크린샷을 같은 업로드 버튼 하나로 인식한다.
- **화면에서 보여줄 것**: 업로드 화면에 "영수증 사진 또는 주문내역 캡처"를 명시해서 두 가지 입력이 모두 된다는 것을 바로 알 수 있게 한다.

### 차별점 3: 대용량 재료를 끝까지 쓰는 3일 식단

- **문제**: 양파 1.5kg망이나 대파 한 단은 한 끼로 다 쓰지 못한다. 한 끼 메뉴만 추천받으면 남은 재료는 다시 방치된다.
- **해결**: 임박 재료를 3일 안에 다 쓰도록 끼니별 메뉴를 짜준다.
- **화면에서 보여줄 것**: 식단 화면에 재료별로 지금 수량과 3일 뒤 남는 수량을 보여준다. (예: 양파 8개 → 0개)

### 기존 앱과 비교

| 기능                          | 프리지    | 냉장고 지킴이 | 킵        | 이 서비스     |
| ----------------------------- | --------- | ------------- | --------- | ------------- |
| 영수증 사진 인식              | O         | O             | O         | O             |
| 임박 재료 우선 표시와 알림    | O         | O             | 확인 필요 | O (알림 제외) |
| 남은 재료 기반 AI 메뉴 추천   | 확인 필요 | O             | O         | O             |
| 온라인 주문내역 스크린샷 인식 | 확인 필요 | 확인 필요     | 확인 필요 | **O**         |
| 요리 후 재고 자동 차감        | 확인 필요 | 확인 필요     | 확인 필요 | **O**         |
| 재료를 다 쓰는 여러 끼 식단   | 확인 필요 | 확인 필요     | 확인 필요 | **O**         |

- O는 앱스토어 설명에 해당 기능이 적혀 있다는 뜻이다. "확인 필요"는 설명에 언급이 없다는 뜻이며, 기능이 없다는 확인은 아니다.
- 발표 전에 각 앱을 설치해서 "확인 필요" 칸을 직접 확인하고 표를 고친다. 이미 있는 기능을 차별점으로 발표하지 않는다.

### 구현 원칙

- 차별점은 데모 녹화에서 눈에 보여야 한다. 위의 "화면에서 보여줄 것"은 각 기능의 필수 요구사항으로 다룬다.
- 시간이 부족하면 차별점 1 → 2 → 3 순서로 지킨다. 차별점 1이 빠지면 기존 앱과 구별되지 않는다.

## 핵심 기능 (구현 우선순위 순)

1. **장보기 인식**: 영수증 사진과 온라인 주문내역 스크린샷을 비전 LLM으로 인식한다. 품목명, 수량(개), 보관 위치(냉장/냉동/실온), 예상 소비기한을 추출하고 봉투, 세제 같은 비식품은 제외한다.
2. **등록 확인**: 인식 결과의 품목명, 수량, 보관 위치, 소비기한을 사용자가 수정, 삭제, 추가한 뒤 저장한다.
3. **냉장고 목록**: 남은 일수(D-day) 순으로 정렬하고 임박 재료를 강조한다. 품목과 수량은 언제든 수정할 수 있다.
4. **한 끼 추천과 차감**: 임박 재료를 우선으로 메뉴를 추천하고 레시피 단계를 보여준다. "요리했어요"를 누르면 차감 확인 화면에서 사용 품목과 수량을 수정한 뒤 차감한다.
5. **3일 식단**: 임박 재료를 3일 안에 다 쓰는 식단을 추천한다. 각 끼니는 4번의 레시피와 차감 흐름을 그대로 재사용한다.

## 규칙

- 수량은 항상 개수(개)로 저장한다. kg, g, L 같은 단위는 등록할 때 LLM이 개수로 변환한다. (예: 양파 1.5kg → 8개, 우유 1L 1팩 → 1개)
- 레시피 사용량도 재고와 같은 단위(개)로 받는다. 레시피에 자주 나오는 "반 개"를 표현하기 위해 0.5개 단위까지 허용한다.
- 소금, 설탕, 간장, 식용유 같은 기본 양념은 재고에 없어도 있다고 가정하고 차감 대상에서 제외한다.
- LLM이 만든 값(품목명, 수량, 보관 위치, 소비기한, 추천 메뉴의 사용 품목과 수량)은 모두 추정값이며, 사용자가 수정할 수 있어야 한다.
- 영수증에는 소비기한이 없으므로 구매일과 품목별 일반 보관 기간으로 추정하고, 화면에 "예상"으로 표시한다.
- 차감은 사용자가 확인한 뒤에만 적용한다. 수량이 0 이하가 되면 목록에서 제거한다.
- 용어는 "유통기한" 대신 "소비기한"을 쓴다. (2023년 소비기한 표시제 시행)

## 범위 밖 (구현하지 않음)

- 회원가입, 로그인, 여러 사용자 간 공유
- 푸시 알림
- 바코드 스캔
- 영양 정보, 칼로리 계산
- 장보기 목록, 쇼핑몰 연동

## 개발 조건

- 1인 개발, 6시간
- 심사 기준: Kiro 사용 35점, 작동(녹화 데모) 30점, 문제 정의 20점, 사용자 가치 15점
- 녹화 데모의 한 흐름이 처음부터 끝까지 안정적으로 동작하는 것을 최우선으로 한다. 기능 추가보다 데모 흐름의 완성도를 우선한다.

## 데모 시나리오

1. 마트 영수증 사진 업로드 → 인식 결과 확인 및 수정 → 저장
2. 온라인 주문내역 스크린샷 업로드 → 같은 방식으로 등록 **[차별점 2]**
3. 냉장고 목록에서 임박 재료 확인
4. 메뉴 추천 → 레시피 확인 → "요리했어요" → 사용 수량 수정 → "양파 8개 → 7개" 확인 → 차감 → 목록 반영 확인 **[차별점 1]**
5. 3일 식단 추천 → 재료별 3일 뒤 남는 수량 확인 **[차별점 3]**
